═══════════════════════════════════════════════════════════════
  HOW TO USE NOW
═══════════════════════════════════════════════════════════════

STEP 1: Install Python packages (first time only)
────────────────────────────────────────────────────────────────
  pip install -r requirements.txt


STEP 2: Configure API key (first time only)
────────────────────────────────────────────────────────────────
  cp .env.example .env
  
  Then edit .env and add:
    GROQ_API_KEY=gsk_your_actual_key_here
  
  Get free key: https://console.groq.com


STEP 3: Launch everything
────────────────────────────────────────────────────────────────
  python start.py

  System will:
    • Check your .env file
    • Verify dependencies
    • Install frontend packages (if needed)
    • Start backend API (port 8000)
    • Start frontend UI (port 3000)
    • Show you when ready

  Open: http://localhost:3000

  Press Ctrl+C to stop both servers

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "Module not found: sentence_transformers"
  → pip install sentence-transformers==3.3.1

❌ "GROQ_API_KEY not set"
  → Edit .env and add your key

❌ "npm not found"
  → Install Node.js: https://nodejs.org

❌ Frontend won't start
  → cd frontend && npm install
  → cd .. && python start.py

❌ Rate limit errors (429)
  → Try simpler goals (less LLM calls)
  → Wait a minute and retry
